## 便宜 VPS 的三個坑，以及怎麼用參數識別

**超售。**「4 核 CPU、8GB 記憶體、不限流量，價格還比同規格低一截」，這種組合幾乎都在超售。實體機資源被五六十台虛擬機瓜分，你那個 4 核是跟別人搶的，高峰期 CPU 跑到 10%、I/O 直接打滿。判斷方法很簡單：用單價除以記憶體，明顯低於同類方案平均值的，多半有代價。JustHost 的 Bright Star 給 4 核 4GB 只要 $9.80，這個價位對應的通常是共享型資源，別指望它能扛住持續滿載。

**跑路。**小商家一上來就推年付特價搶現金流，是這個行業最常見的倒閉前兆。對策只有一條：新商家第一次交易不押超過三個月。

**線路。**大部分極便宜的境外 VPS 走普通 BGP 甚至直連，國內晚高峰丟包率飆升、延遲動輒 200ms 以上。有中國大陸優化的線路是另一個價位：DMIT 的 CN2 GIA 洛杉磯到國內三網約 150–180ms，香港節點 20–50ms，代價是香港 Pro 系列 $39.90/月起。JustHost 官網沒有標示 CN2、CMIN2 或任何中國大陸優化線路，機房清單覆蓋四十多個國家、八十個機房，主打的是「哪個機房慢就換一個」的靈活性。如果你的訪客主要在中國大陸，這家的定位不對，別為了省幾美元去賭。

## 常見問題

**便宜 VPS 能建站嗎，能扛多少流量？**
能。1 核 1GB 跑靜態站或輕量 WordPress，日訪問幾百到一兩千沒問題。真正的瓶頸通常不是 CPU，是記憶體和資料庫查詢。日流量上萬的站，這個價位不合適。

**隔年續費會不會漲？**
JustHost 的價格頁把 $4.85 和年付 $3.88 並列標示，沒有「首年優惠」字樣，看起來不像那種第二年翻倍的定價方式。但官網沒有公開續費條款，下單前把價格頁截圖存檔，第二年帳單出來對照。

**IP 被封怎麼辦？**
JustHost 官網寫的是可在用戶中心隨時更換 IP，沒有標次數限制。業界常見做法有兩種可以參照：DMIT 每 15 天可免費換一次被封 IP，超頻 $5/次；RackNerd 購買後 72 小時內可免費換一次。買之前先確認更換是否收費。

**能裝 Windows 嗎？**
官網列出的是一鍵部署的 Linux 發行版與應用鏡像，沒看到 Windows 選項。需要 Windows 得自備授權自行安裝，或直接找標明提供 Windows 的方案。

**買了需要備案嗎？**
備案只針對中國大陸境內機房。JustHost 的節點都在境外，不涉及備案。若你之後改買國內機房（例如雨雲的紹興 BGP），那就必須備案。

**付款方式和幣種？**
官網同時有美元與人民幣兩套標價頁面，中文站按人民幣計價。實際可用的支付方式請在下單頁確認，本文沒有核驗到具體的支付渠道清單。
